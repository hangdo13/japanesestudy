# Avatar

Ảnh đại diện tròn (hoặc chữ viết tắt trên nền pastel), và nhóm avatar chồng nhau với số `+N`.

Lấy từ: avatar người học và nhóm "+12" trong lớp sắp tới (cả hai reference).

## Quy tắc
- Khi có ảnh: `<img>` bo tròn cùng kích thước; không ảnh thì 2 chữ cái đầu trên nền tint (`a1`–`a4`).
- Nhóm chồng nhau lệch `-8px`, viền `surface` 2px để tách.
- `kt-avatar--ring`: vòng `peach` = đang giữ chuỗi ngày học.
