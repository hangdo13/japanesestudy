# SkillTile

Ô vuông bo góc nền nhạt mang chữ đại diện hoặc icon của kỹ năng — dấu hiệu nhận biết kỹ năng xuyên suốt app.

Lấy từ: các ô icon pastel trước tên môn học (reference tablet).

## Bảng kỹ năng
| Kỹ năng | Class | Ký hiệu |
|---|---|---|
| Từ vựng | `kt-skill--vocab` (xanh trời) | 語 |
| Ngữ pháp | `kt-skill--grammar` (tím dừa cạn sáng) | 文 |
| Kanji & đọc | `kt-skill--kanji` (hồng tươi) | 字 |
| Nghe – nói | `kt-skill--speaking` (xanh bạc hà) | icon mic |
| AI | `kt-skill--ai` (xanh dương thương hiệu) | icon |
| Thành tích | `kt-skill--reward` (peach) | icon |

Kích thước: `--sm` 32, mặc định 40, `--lg` 48.
