# Greeting

Lời chào đầu trang chủ: "Chào," chữ thường + tên chữ đậm, dòng phụ màu `ink-muted` có tên app tô `primary-ink`.

Lấy từ: "Hello, **Tommy!**" (reference điện thoại) và "Welcome Back, Oliver!" (reference tablet).

## Quy tắc
- Dòng phụ nên là một lời nhắc hành động cụ thể ("Còn 2 bài để giữ chuỗi") thay vì khẩu hiệu.
- Đổi theo giờ: "Chào buổi sáng" / "Chào buổi tối" làm app có cảm giác sống động mà không cần thêm hình.
