# SearchField

Ô tìm kiếm dạng viên thuốc, nền `surface`, viền `line`; khi focus viền chuyển `blue` + vầng sáng `blue-soft`.

Lấy từ: "Search Courses…" (reference tablet).

## Quy tắc
- Placeholder gợi ý được tìm gì: "Tìm bài học, từ vựng, kanji…". Cho phép gõ romaji, kana hoặc tiếng Việt.
- `kbd` phím tắt chỉ hiện trên web/tablet có bàn phím.
