# CourseListItem

Dòng khoá học/bài giảng: ô kỹ năng, tên + chủ đề, thời lượng, nút phát vuông nhỏ. Dạng `kt-item--plain` không có khung, ngăn bằng đường `line`.

Lấy từ: "My Courses" với thời lượng và nút ▷ (reference tablet).

## Quy tắc
- Bài đang phát đổi icon thành `pause`; chỉ một bài phát tại một thời điểm.
- Ô kỹ năng dùng chữ đại diện (語 文 字) hoặc icon (mic cho nghe nói) — giữ nhất quán trong một danh sách.
