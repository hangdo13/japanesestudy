# SectionHeader

Tiêu đề mỗi khối nội dung (18px/700) với hành động phụ bên phải: link "Xem tất cả", bộ chọn "Hôm nay ▾" hoặc nút thêm.

Lấy từ: "My Courses · View All", "My Schedule · Today ▾ · +" (reference tablet).

## Quy tắc
- Link dùng `ink-muted`, hover chuyển `primary-ink`. Không gạch chân.
- Cách nội dung bên dưới `space-3`; cách khối phía trên `space-6`.
