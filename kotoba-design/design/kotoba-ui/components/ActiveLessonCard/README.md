# ActiveLessonCard

Thẻ nổi bật nhất trang chủ — bài đang học dở, nền `surface-tint`, tiêu đề lớn 26px, avatar bạn cùng học và chip đánh giá.

Lấy từ: thẻ "Intro to Front-End Development" mục Active Lessons (reference điện thoại).

## Quy tắc
- **Một thẻ `surface-tint` mỗi màn hình.** Đây là điểm nhấn duy nhất giúp giao diện sạch mà không nhạt.
- Avatar ở đây dùng viền `surface-tint` (`kt-avstack--on-tint`) để hoà với nền thẻ.
- Nút ↗ trắng = học tiếp từ đúng chỗ đã dừng.
