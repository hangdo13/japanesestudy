# ProfileCard

Thẻ hồ sơ: avatar có vòng `peach`, tên + lớp, chip xếp hạng, và chuỗi ngày học ngay bên dưới.

Lấy từ: khối "Profile · Oliver Bennett · 3rd Ranking · 6 Days Learning Streak" (reference tablet).

## Quy tắc
- Vòng `peach` quanh avatar nghĩa là "đang giữ chuỗi" — mất chuỗi thì bỏ vòng.
- Chip hạng chỉ hiện khi người học bật bảng xếp hạng (mặc định tắt — cạnh tranh không hợp với mọi người).
