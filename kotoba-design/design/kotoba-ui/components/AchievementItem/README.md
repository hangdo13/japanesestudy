# AchievementItem

Dòng thành tích: ô icon nền `peach-soft` (`kt-skill--reward`), tên huy hiệu, điều kiện đạt, điểm XP màu `peach-ink` bên phải.

Lấy từ: "Recent Achievements · Quick Learner +100 XP" (reference tablet).

## Quy tắc
- XP luôn màu `peach-ink`, đậm, có dấu `+`. Peach là điểm ấm duy nhất trong bảng màu lạnh — chỉ dành cho phần thưởng.
- Tên thành tích ngắn (1–2 từ), phụ đề nói rõ đã làm gì.
- Khi vừa đạt: thẻ trượt lên + rung nhẹ (haptic) — đây là chỗ đáng dùng micro-interaction.
