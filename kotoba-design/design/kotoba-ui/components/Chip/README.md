# Chip

Nhãn nhỏ dạng viên thuốc 28px: đánh giá, xếp hạng, AI, trạng thái, cấp độ JLPT, kỹ năng.

Lấy từ: chip "★ 4.8" (reference điện thoại), "3rd Ranking" và "Powered By Ascend" (reference tablet).

## Quy tắc
- Chip chỉ để hiển thị; nếu bấm được thì dùng `Button --sm`.
- Màu chip kỹ năng khớp với `SkillTile`.
- Tối đa 2 chip cạnh nhau trên một thẻ.
