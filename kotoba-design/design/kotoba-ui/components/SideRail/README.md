# SideRail

Thanh điều hướng dọc cho tablet và web: logo trên cùng, icon ở giữa, cài đặt + avatar dưới cùng.

Lấy từ: cột icon bên trái của dashboard (reference tablet).

## Quy tắc
- Rộng 72px, chỉ có icon — mỗi nút phải có `aria-label` và tooltip khi hover.
- Mục đang chọn: nền `surface-sunken`, icon `ink`; còn lại `ink-muted`.
- Tối đa 6 mục ở giữa. Nhóm mục ít dùng xuống dưới `kt-rail__spacer`.
