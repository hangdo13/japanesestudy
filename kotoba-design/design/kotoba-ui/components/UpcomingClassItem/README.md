# UpcomingClassItem

Dòng lớp học sắp tới: nút chuông, tên lớp, giờ, avatar người tham gia. Lớp gần nhất mở rộng (`kt-item--feature`) với nút "Vào lớp".

Lấy từ: "Upcoming Classes · Connect to Class" (reference tablet).

## Quy tắc
- Chỉ lớp gần nhất được mở rộng và có chuông nền tối (`kt-iconbtn--dark`).
- Giờ dạng 24h `16:00 – 17:00` với dấu gạch ngang có khoảng trắng.
- Quá 3 avatar thì gộp thành `+N`.
